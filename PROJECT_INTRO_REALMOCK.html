1一句话定位

RealMock = 本地优先、BYOK、三服务模块化单体的 AI 模拟面试平台。后端由 services/main.py 聚合 api_service、agent_service、interview_service 三个 FastAPI 路由，共享 shared/ 平台能力；前端由 apps/web/ 下的 Next.js 14 应用承载面试房间、报告页、辅导页、3D 形象与全套语音/视频/动效。

它想解决的核心问题："在没有真人面试官时，候选人也需要一遍近乎真实、覆盖全流程、且能被打分和复盘的模拟面试。"由此派生三条主线：

  • 让对话真实：基于工作流（technical / hr / management）多阶段推进；候选公司决定面试风格；人设（5 种）与风格（4 种）共同塑形。
  • 让对话有依据：候选人简历被解析为结构化档案；GitHub MCP 风格工具核验项目；RAG 注入企业知识库；联网检索面经；函数调用循环最多 3 轮。
  • 让对话可复盘：每场生成结构化报告、评分维度、训练计划；候选人成长库（GrowthRecord）跨场次沉淀弱项；系统级学习（system_learning.json）反哺后续面试官提示。

def create_app() -> FastAPI:
    app = FastAPI(
        title="RealMock API",
        description="RealMock 模拟面试平台聚合入口（api + agent + interview 三服务）",
        version="1.0.0",
        lifespan=lifespan,
    )

    # X-Request-Id 注入 + 校验（只允许 [A-Za-z0-9_-]{8,64}）
    @app.middleware("http")
    async def trace_middleware(request, call_next): ...

    # CORS 严格策略：prod 禁用 * 通配
    _check_cors_policy(settings)
    app.add_middleware(CORSMiddleware, ...)

    # prod 强制要求 SECRET_KEY（不允许依赖自动生成的 data/.secret.key）
    _check_secret_key_policy(settings)

    # 路由聚合（注入 /api/v1 前缀）
    app.include_router(api_router,     prefix="/api/v1")
    app.include_router(agent_router,   prefix="/api/v1")
    app.include_router(interview_router, prefix="/api/v1")

    # 3 个月滚动兼容：同时挂 /api 别名
    _legacy = APIRouter()
    for r in (api_router, agent_router, interview_router):
        _legacy.include_router(r, prefix="/api")
    app.include_router(_legacy)

    # 统一 envelope：5 个异常 handler
    app.add_exception_handler(RequestValidationError, on_request_validation)
    app.add_exception_handler(HTTPException, on_http_exception)
    app.add_exception_handler(StarletteHTTPException, on_starlette_http_exception)
    app.add_exception_handler(UnsafeURLError, on_unsafe_url)
    app.add_exception_handler(Exception, on_unhandled_exception)

    @app.get("/health")
    def health():
        return {"status": "ok", "service": "realmock", "version": "1.0.0"}

    return app

lifespan：同步 IO 不阻塞事件循环

services/main.py · L76-108snippet
@asynccontextmanager
async def lifespan(app):
    # 建表 + 列迁移 + 处理器配置 seed（同步 IO 走 to_thread）
    await asyncio.to_thread(_bootstrap_db_and_seed)
    # 首次启动构建企业知识库 RAG 索引（失败不阻断）
    await ensure_rag_index()
    logger.info("RealMock 后端已启动 env=%s", settings.env)
    try:
        yield
    finally:
        if not settings.is_prod and os.environ.get("TEST_MODE") == "1":
            logger.debug("测试模式：跳过 engine dispose")
        else:
            try:
                await asyncio.to_thread(_shutdown_engine)
            except Exception:
                logger.exception("关闭阶段释放引擎失败")
        logger.info("RealMock 后端已关闭")

这是一个非常优雅的写法：所有磁盘 IO（SQLite 建表、列迁移、写 seed、Chroma 索引构建）都被丢到线程池，事件循环永远不会因为磁盘慢而抖动；同时也只在 prod 关闭引擎，测试模式（TEST_MODE=1）下保留引擎给后续 fixture 用。

7shared/ 共享层：平台能力

三个服务都依赖的"基础设施工具箱"。通过 pyproject.toml 中 pythonpath = ["services"] 配置，使得 shared.* 可被 pytest 直接 import 为顶层包（无需 sys.path 注入）。

核心模块（shared/core/）

config.py

Settings 来自 pydantic-settings，get_settings() 缓存单例。涵盖 LLM BYOK、嵌入、语音、RAG 后端、信任代理、Cookie Secure、限流信任链等。

database.py

SQLAlchemy 2.0 DeclarativeBase。get_engine() 线程安全双检锁懒创建；get_session_factory() 同样。SQLite 自动启用 WAL + busy_timeout + synchronous=NORMAL + 外键。

errors.py / error_handlers.py

错误码目录 CATALOG（A0/A1/A2/A3/A4/B/C 四段式）；ApiBusinessError 继承 HTTPException 携带 error_code/hint/retryable；5 个 handler 共用 envelope。

logging.py

JSON SafeFormatter + RedactFilter（自动脱敏 API Key / Authorization / PEM 块）。trace_id 走 ContextVar。

secrets.py

AES-256-GCM（cryptography）。enc:v2:<salt>:<nonce>:<tag>:<cipher> 格式；旧 enc:v1 显式抛 LegacySecretFormatError 拒绝静默迁移。Master key 来自 SECRET_KEY env 或 data/.secret.key。

session_auth.py

能力令牌（capability token）：HttpOnly Cookie iv_{id} / prep_{id}；也支持 X-Interview-Token Header；生产拒绝 query ?token=。CSRF 缓解（仅 cookie 鉴权时校验 Origin/Referer）。

ratelimit.py

# 句末硬切分点 + 长句软切（字数达标后）
_HARD_END  = frozenset("。！？!?；;…\n")
_SOFT_BREAK = frozenset("，、,")
_SOFT_MIN_ROTATION = (10, 14, 18, 24, 32)
_SOFT_MIN_CHARS = 18

def should_flush_sentence_buffer(buf, soft_min=None):
    if not buf: return False
    last = buf[-1]
    if last in _HARD_END: return True
    min_chars = soft_min if soft_min is not None else _SOFT_MIN_CHARS
    if len(buf) >= min_chars and last in _SOFT_BREAK: return True
    if len(buf) >= 48: return True   # 超长硬切
    return False

def next_soft_min(index):
    mins = _SOFT_MIN_ROTATION
    i = index % len(mins)
    return mins[i], index + 1

21提示词与中文化约束

shared/core/prompts.py 提供三件事：

  • with_agent_output_rules(system_prompt)：在 system 末尾追加统一"禁用 emoji / 全角标点"约束（幂等）；
  • strip_emojis(text)：出站前硬删除 emoji（覆盖国旗 / 杂项符号 / 表情 / 交通地图 / 装饰 / ZWJ 等 30+ Unicode 区块）和颜文字；
  • normalize_cn_punctuation(text) / normalize_cn_punctuation_tree(value)：递归把中文字境下的半角标点 (`,.;:!?()`) 转换为全角，纯 ASCII 片段不动。

所有面向用户 / 解析用的 system prompt 都会通过 with_agent_output_rules 包装；流式 token 实时调用 strip_emojis（在 llm_client.chat_stream）。

几个典型的 prompt 实践：

  • 强约束：禁止使用任何 emoji 表情符号、颜文字、绘文字或表情包式符号；
  • 中文标点：中文正文必须使用全角标点：，。；：！？、（）「」；英文专有名词、代码标识符、URL 保持半角；
  • 控制标记：[PHASE_COMPLETE] / [INTERVIEW_COMPLETE] / [emotion:smile]，由客户端解析后渲染，不念出；
  • 思考块：... 与 ...，被 ThinkStreamFilter 过滤；
  • 能力声明：可用工具（function calling）你可以使用以下工具获取真实信息，引导 LLM 优先用工具核实项目细节。

代码健壮性的亮点（值得保留的）

  • 三层 X-Request-Id 注入：HTTP 中间件 + WS 握手 + 日志 contextvar 串联
  • DNS Pin + SSRF 黑名单：缓解 DNS rebinding + 私网/loopback 拒绝
  • AES-256-GCM at-rest + 旧 enc:v1 显式抛错
  • WS 心跳 + 顶替机制：30s ping、3 次失败断开、单会话单连接
  • 报告防双打：进程内锁 + DB 哨兵 + 失败清哨兵
  • 流式思考块剥离：ThinkStreamFilter 跨 token 切分也安全
  • 回采检测：SequenceMatcher + 子串包含，避免扬声器误拾
  • SQLite WAL + busy_timeout：WS 回合写状态与后台报告并发
  • HTTP-only Cookie + WS 子协议兼容：防止令牌落 URL 日志
  • 反 prompt 注入：搜索不可用时返回 SEARCH_UNAVAILABLE 引导 LLM 不要编造

29部署 / 运维

环境要求

  • Python ≥ 3.11（pyproject mypy 锁 3.12，requirements 不强制）；
  • Node ≥ 18（Next.js 14）；
  • SQLite ≥ 3.35（WAL + busy_timeout 支持）；
  • 反向代理（Nginx / Caddy / Cloudflare）处理 TLS + X-Forwarded-Proto / X-Forwarded-For；
  • 首次启动：建表 + 列迁移 + seed（自动）；
  • 数据目录：services/shared/data/（含 app.db / .secret.key / chroma/ / system_learning.json / uploads/）。

反向代理要点

  • Cookie Secure：HTTPS 部署 → COOKIE_SECURE=true（或自动）；
  • WebSocket 升级：Nginx proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; + 60s+ proxy_read_timeout；
  • 缓冲关闭：SSE 端点要 proxy_buffering off（已在响应头 X-Accel-Buffering: no）；
  • 信任链：TRUSTED_PROXY_CIDRS=10.0.0.0/8，让限流信任 X-Forwarded-For；
  • 跨域：CORS_ORIGINS=https://your.app（禁止通配）。

生产门禁（启动时检查）

  • ENV=prod → 拒绝 ALLOW_LOCAL_LLM=true；
  • SECRET_KEY 缺失 → 报错（不能用自动生成的 .secret.key，否则跨机器后 API Key 密文不可解密）；
  • CORS 包含 * → 报错；
  • URL 校验要求 https。

运维建议

  • 备份：services/shared/data/ 整目录（含 .secret.key、chroma）；
  • 日志：JSON X-Trace-Id 串接；
  • 限流：默认桶足够；多 worker 时每个 worker 独立计数（注释里写明）；
  • 升级：列迁移自动；前端 next start 即可。

  1. 三服务业务零循环，所有跨服务通信仅经 shared。
  2. 思考 LLM Key 与 ASR Key 物理隔离，build_stt_credentials 注释里写明。
  3. 面试每阶段题量有 min/max，由 LLM 输出的 [PHASE_COMPLETE] 标记或题数达 max 推进。
  4. WS 单会话单连接：新连接顶替旧连接，发 error(B2003) + close(4000)。
  5. 报告防双打：进程内锁 + DB 哨兵 {"_generating":true} + 失败清哨兵。
  6. 能力令牌：access_token 仅在创建响应写 HttpOnly Cookie，不在 list / get 响应回传。
  7. CORS：prod 禁用 * 通配；URL 出站经 make_pinned_async_client DNS pin。
  8. SECRET_KEY：prod 必须显式提供（≥16 字节），否则 data/.secret.key 不可跨机器迁移。
  9. 流式思考块：<think>...</think> / <thinking>...</thinking> 由 ThinkStreamFilter 剥离（跨 token 切分安全）。
  10. 回采检测：SequenceMatcher.ratio >= 0.55 或前缀 40 字符子串包含，丢弃并提示 C2001。
  11. SQLite WAL + busy_timeout：WS 写状态与后台报告并发安全。
  12. 追问信号：在反问/总结/寒暄阶段 不触发技术性 missing_data / tech_hole。
